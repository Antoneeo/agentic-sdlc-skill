# Feature Vision: Pick List

## Problem
An accepted order is still ambiguous to the operator: two widgets share a name.

## Expected Benefit
The operator picks the right widget without asking the clerk.

## Actors
Warehouse operator (see the project Vision's `## Actors`).

## Success Signals
- Zero pick-clarification messages per week.

## Non-Goals / Out of Scope
- Route optimization inside the warehouse.

## Related Constraints and Principles
- Read the warehouse tool; never write to it (`principles.md`).
