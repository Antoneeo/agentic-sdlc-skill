# Course Creator — beta

`course-creator` helps an AI agent create a course for a defined learner. It maps what the learner already knows, orders concepts by prerequisite, writes explanations in progressive modules, and links factual statements to reopenable sources. Independent fresh learner agents can expose confusing steps; their results are diagnostic. The course is labeled **efficacy not verified** until enough evidence from real learners supports a narrower claim.

The package is the fourth lens of the Agentic SDLC family. It uses the shared `ai_docs/` project memory and governance. Version 0.1.0-beta.4 supports Standalone mode. This is an experimental beta: the authoring method and artifact contracts may change; human learning efficacy has not been established. Its course artifacts remain readable without the skill. Each new course keeps a verbatim, append-only record of the requester's own words and decisions in `audit/requests/`, cited by the analysis and checked by its reviews.

## What's new in 0.1.0-beta.15

**An instructor-led course ships with everything its instructor needs.** A course taught by an instructor now comes with `INSTRUCTOR_GUIDE.md`. It tells the instructor what to prepare, the schedule, what not to show the learners, what to do when a live step goes wrong, and what to clean up afterwards. It also lists every material the delivery needs. The course check confirms that each listed material exists, so a missing file shows up before the session instead of during it.

**Feedback is attributed to the right version.** If a slide or unit names the course with a version different from the one the course declares (say "version 1.0" in a course at 1.2), the check names the section and the version it found. Feedback that quotes the version then reaches the version it is about.

**Demo projects stay out of the course's memory.** Materials can be listed anywhere in the project, so demo projects and the generated deck are listed where they are. If a listed demo project with its own repository sits inside `ai_docs/`, the check warns you: its documents would otherwise turn up in project searches as if they were the course's.

**From 0.1.0-beta.14, published without notes:**
- **The process checks can no longer be bypassed by accident.** Quoting a work level inside a sentence no longer counts as declaring it, and protected parts of the project stay protected when the agent changes folder.
- **You know what the project memory has not read yet.** The agent can tell how much of the project it has never examined.

## Install and initialize

```sh
npm install -g @antoneeo/course-creator
course-creator-install-skill
cd YOUR_PROJECT
course-creator-init
```

The installer detects Claude Code, Gemini CLI, Codex and Google Antigravity. Initialization creates absent `ai_docs/` files and a project protocol pointer; it does not overwrite existing project documents. Use `python <skill_dir>/scripts/sdlc_check.py check --root .` to validate the shared SDLC and course structures.

**Docs site** (`scripts/docs_site.py --root <project> [--open] [--zip <file>]`): a static, offline, read-only website of what the agent reads in the project — reading guide, Vision, rules, documents, open work with each next step, courses and, with a knowledge base, the topic map, each fact with its exact source passage, and the source documents. Written to `.docs-site/` (added to `.gitignore` on the first run), outside `ai_docs/`; nothing is ranked or recommended.

Using the skill in your own project carries no obligation to publish your course or its sources. See [LICENSE](LICENSE) for the software terms and [NOTICE](NOTICE) for attribution.

## Primary course output

New courses deliver a complete textual source for every slide (`SLIDE_CONTENT.md`), with exact learner copy, full explanations, examples, visual contents, transitions and answers. PPTX and other renderings are optional. Explicit non-slide requests retain a complete textual source for their units. Every course must show distinguishable value for its audience through an explanatory contribution and a transfer task; structure or simulated success does not establish human efficacy. See `skills/course-creator/slide_content.md`.

A course delivered by an instructor (`Delivery mode: instructor-led`) also ships `INSTRUCTOR_GUIDE.md`: what to prepare, the schedule, what to keep out of the learners' view, what to do when a live step fails, what to clean up afterwards, and the list of every material the delivery needs, wherever it is in the project, checked to exist. `course_check` refuses an instructor-led course without the guide, or with a guide that does not follow the template in `templates.md`. An existing instructor-led course therefore fails `check` until its guide is written to that template. In any course with a content contract it also refuses a line that names the course with a dotted version other than the declared `Course version`.

Course design now uses outcome-first evidence, teaching/assessment alignment, visible worked reasoning, proportionate support, cognitive-load management and retrieval opportunities. `learning_design.md` records the pedagogical sources and the source-informed semantic review rubric; a locator table or structural PASS is not proof of learning.
