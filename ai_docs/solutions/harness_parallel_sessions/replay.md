# F-088 replay — instructions for a cold reader

You have no context but this file, `cases.md` beside it, and the doctrine files named below.
Read-only: write nothing.

1. Read `cases.md`.
2. Read the doctrine files you are given, whole. Old text (baseline): `SKILL.md`,
   `templates.md`, `elicitation.md`, `review.md`, `dispatch.md`, `hybrid.md` of the skill
   directory named in your brief. New text (candidate): the same set plus `coordination.md`.
3. For each case C0–C8 answer the replay question in `cases.md`: FLAGGED — the observed
   behaviour violates a rule, or a rule tells the agent what to do in that situation — or
   NOT FLAGGED. For FLAGGED quote the governing sentence (under 30 words) with
   `file:line`. A rule that only resembles the situation is NOT FLAGGED: say what it misses.
4. Return one table: `| case | verdict | file:line | quoted rule | what it misses (if any) |`,
   then one line per case you found ambiguous.

The author's expected verdicts are kept apart from this file on purpose: a reader told the
answer tends to find it.
