You have no context but this file, `cases.md` beside it, and the doctrine files named below.
Read-only: write nothing.

1. Read `cases.md`.
2. Read the doctrine files you are given, whole: `SKILL.md`, `coordination.md`,

3. For each case G1–G9 answer the replay question in `cases.md`: FLAGGED — a rule allows,
   forbids or routes what the session does — or NOT FLAGGED. For FLAGGED quote the

   A rule that only resembles the situation is NOT FLAGGED: say what it misses.

answer tends to find it.
