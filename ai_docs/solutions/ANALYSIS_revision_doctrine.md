## Interface Contract
- **S1 — SKILL.md `## Revision — the full re-read`** (placed after `## The Capture Moment`, the F-039/F-040 gesture-section idiom). Budget ≤15 lines; clauses (f)-(h) are compressed to one line each in the shipped text — the parentheticals below are ANALYSIS rationale, not doctrine text. The clauses:
  - (a) before editing, re-read the WHOLE document;
  - (b) rewrite the body so it reads as written today — new knowledge FUSED, not quarantined in dated sections;
  - (c) history goes to the Diary/notes, never an inline chronicle — and past Diary entries are NEVER rewritten: a correction is a new entry;
  - (d) a SUPERATO/SUPERSEDED banner is a tombstone for a superseded DOCUMENT, never a revision device inside a living one;
  - (e) the honest limit, in the doctrine's own text: the re-read raises the probability of catching a false premise — domain judgment stays the human's;
  - (f) why the failure is structural: anchored edits are each correct; the global invariant is never re-verified;
  - (g) **claim tables are EXEMPT** — rows move only per `reconciliation.md` (`SUPERSEDED` rows keep their text, `CONTESTED` sets stay marked until information ends the disagreement), **and node frontmatter (`parents:`/`related:`) moves only per `taxonomy.md` — a revision never re-parents**; the rewrite governs prose, never the ledger or the graph edges (without this clause the doctrine instructs the forbidden act: the machine deciding);
  - (h) a multi-document pass runs the full re-read PER DOCUMENT — delta coverage across the set never substitutes for each document's integrity (the post-mortem's own amplifier, named).
