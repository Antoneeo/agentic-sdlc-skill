# M3 — decide validity
Course Alda, version 1.0, module M3. Profile: novice. Objective O3.
## explanation
Rotate the first token, keep the second token unchanged, look up both numbers, and add them. The receipt is valid exactly when that total equals its seal. Example: first Neri, second Sora, seal 8. Neri rotates to Luma (2); Sora stays Sora (6); 2 + 6 = 8, so the receipt is valid. If the seal were 9, it would be invalid. Apply these steps to a new receipt before looking at the answer.
## check
For first Luma, second Neri, seal 10: Luma rotates to Sora (6); Neri stays 4; 6 + 4 = 10, so valid. Feedback channel: not available in this exercise.
