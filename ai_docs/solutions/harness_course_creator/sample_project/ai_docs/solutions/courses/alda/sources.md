# Alda exercise specification

## definitions

Alda is invented for this course fixture. Its token values are Luma = 2, Neri = 4, Sora = 6. To rotate the first token, replace Luma with Sora, Neri with Luma, or Sora with Neri. A receipt is valid exactly when the value of the rotated first token plus the value of the unchanged second token equals the seal. These are stipulated rules of this exercise, not claims about any real protocol.
