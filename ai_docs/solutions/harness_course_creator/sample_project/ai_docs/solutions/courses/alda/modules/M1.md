# M1 — token values
Course Alda, version 1.0, module M1. Profile: novice. Objective O1.
## explanation
An Alda receipt has two named tokens and a number called the seal. Think of each token as a card with a number printed on it. Luma means 2, Neri means 4, and Sora means 6. The names are invented for this exercise. First learn to replace a token name with its number: Neri means 4. The next module changes the first token before we add.
## check
What number does Sora stand for? Answer: 6.
