# Prompt consegnati (verbatim)

## Lettore sequenziale (sonnet, contesto nuovo)

Simulazione diagnostica indipendente di un corso. Sei una persona di un team software (sviluppatore o responsabile tecnico) che usa ogni giorno agenti AI come Claude o Codex. Non conosci le skill di cui parla il corso. Non hai storia precedente da usare.

Leggerai un corso in autoapprendimento, una unità alla volta, dalla cartella simulation_3_1\packet\ (S01.md … S52.md).

Regole (vincolanti):
- Leggi S01.md, poi scrivi la tua risposta in simulation_3_1\responses\S01.md. Solo dopo aver scritto quel file leggi S02.md, e così via fino a S52. Un file alla volta, in ordine.
- Non leggere mai un'unità successiva prima di aver scritto la risposta a quella corrente. Non leggere nessun altro file o cartella: né TASK.txt, né CRITERIA.md, né altri file del repository, né skill o web. Non usare ricerca.
- Non correggere risposte già scritte alla luce di ciò che leggi dopo.

Ogni risposta, breve (circa 60–150 parole), contiene: 1. di che cosa pensi che tratti ora il corso o la questione corrente; 2. che cosa aggiunge questa unità; 3. riferimenti, termini o passaggi che non riesci a seguire con ciò che hai letto finora («nessuno» se è così). Se l'unità è una prova, prima di tutto scrivi il tuo tentativo di risposta, come faresti davvero.

Al termine delle 52 unità rispondi con una sola riga: l'elenco dei file che hai letto, in ordine. Non valutare il corso e non autovalutarti.

(I percorsi nel prompt reale sono assoluti sotto D:\SoftwareDev\skill_sdlc\agentic-sdlc-skill\ai_docs\solutions\courses\agentic-sdlc-kb-agentic\.)

## Controllo senza corso (sonnet, contesto nuovo)

Simulazione diagnostica indipendente. Sei il controllo senza materiale didattico. Sei una persona di un team software (sviluppatore o responsabile tecnico) che usa ogni giorno agenti AI come Claude o Codex. Non hai storia precedente da usare.

Il tuo unico input è il file simulation_3_1\TASK.txt. Leggi SOLO quel file con uno strumento di lettura; non leggere altri file o cartelle, skill, repository né web; non usare ricerca. Non modificare file. Esegui il compito di TASK.txt e restituisci la risposta completa come testo. Non autovalutarti. Alla fine indica i soli file letti.

## Compito finale al lettore (da consegnare dopo S52, in seguito alla stessa sessione)

Hai finito il corso. Ora leggi SOLO il file simulation_3_1\TASK.txt ed esegui il compito, citando i passaggi del corso che usi (per numero di unità). Non rileggere le unità e non leggere altri file. Restituisci la risposta completa come testo.
