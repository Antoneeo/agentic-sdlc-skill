# Guide: Changes copied across the skill distributions

## When this applies
[source: skill-family-copy-count.md#ruling]
Triaging (Rule Zero) a change in this repository that is copied identically into the
sibling distributions under `distributions/`.

## The rule
[source: skill-family-copy-count.md#ruling]
A change copied identically into the distributions counts **once** against Rule Zero's
file limit. Every other criterion of the level (API, behaviour, security area, design)
applies unchanged. [not covered by source: copies that differ between lenses]
