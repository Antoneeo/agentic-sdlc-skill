## Notes
- Vision documents sit above strategic architecture docs: they explain why the project exists and where it should not go.
- Architecture, analysis, and tests remain mandatory, but they must now be interpreted through the Vision Gate.
- Status describes each milestone itself. This table is a "milestones and sequencing" home `project_vision.md` names under *Where the rest lives*, alongside the evolution roadmap (`vision/roadmap_evoluzione_agenti.md`). It is a record of what was delivered, not a queue: no row is an unstarted item awaiting selection, it carries no per-document state, and it is not consulted to decide which document to work on next — per-document state stays in each document's own frontmatter.
- Row status is a dated snapshot, last updated 2026-08-01; the frontmatter status above is this document's own lifecycle.
- F-numbers resolve in `strategic/features_history.md` (generated); per-feature detail lives in `solutions/ANALYSIS_*.md`. "Release HELD" on F-022 is the owner's publication decision of 2026-08-01: the three packages are built and not published until the kb Knowledge Method is effective — effective meaning the kb success signal above is met. A note about publishing, not a dependency an agent reads to sequence work.
